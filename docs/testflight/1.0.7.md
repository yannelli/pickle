This build fixes save imports.

What changed:
- Import save: a restored pickle comes back in the condition that the preview shows. Before this fix, a backup older than about 5 days always came back dead.
- The age of the pickle still counts from the time that it hatched. An old backup can come back at an older stage.

Please check:
1. In Settings, export a backup.
2. Import the backup.
3. Choose Restore this pickle. Make sure that the stats and the condition are the same as in the preview.
4. Import a backup that is more than 5 days old, or a backup from the web game. Make sure that the pickle is alive.
5. Choose Undo import. Make sure that your previous pickle comes back.

Report the device, the iOS version, the steps, the expected result, and the actual result. Send a screenshot or a video if it helps.
